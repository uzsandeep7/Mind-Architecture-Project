IntroductionThe MIND Architecture Web Application is an online platform designed to support public visitors, registered users, premium members, and administrators. The website provides access to services, events, books, consultation booking, member features, and content management functions.This manual explains how to use the website safely, effectively, and efficiently.2. Purpose of the WebsiteThe purpose of the website is to:provide public information about MIND Architectureallow users to register and log inallow users to browse books and eventsallow users to purchase booksallow users to book eventsallow users to upgrade to premium membershipallow users to request consultationsprovide an admin panel for managing content and users3. Intended UsersThis website is designed for the following user groups:Public visitors who want to browse informationRegistered users who want to manage bookings, orders, and profile detailsPremium members who want access to premium-only content and pricingAdmin and owner users who manage website content, users, orders, and events4. System RequirementsTo use the website properly, users should have:a modern web browser such as Google Chrome, Microsoft Edge, Safari, or Firefoxa stable internet connectionan email address for account registrationa valid payment method for purchases and membershipsJavaScript enabled in the browser5. Public Website FeaturesPublic visitors can access the following pages without logging in:HomeAboutProgramsResourcesGalleryTestimonialsInsightsMembershipContactBook ConsultationPublic users can:view published books, events, and blog contentread business informationbrowse testimonials and gallery itemsaccess consultation and contact pagesPublic users cannot:access the user dashboardaccess the admin panelplace orders without signing inaccess members-only content if restricted6. Creating an Account and Logging In6.1 Create an AccountTo create an account:Open the website.Click the account icon or go to the Sign In page.Select the registration option.Enter the required details such as full name, email, and password.Submit the registration form.If email verification is enabled, verify the email address before logging in.6.2 Log InTo log in:Open the Sign In page.Enter the registered email address and password.Click Sign In.After successful login, the user will be redirected to the dashboard.6.3 Google LoginIf Google login is enabled:Open the Sign In page.Click Continue with Google.Choose the Google account.Approve the login request.The system will redirect the user back to the website.7. User DashboardThe user dashboard allows registered users to manage their account and activities.Users can:view profile detailsupdate full nameview membership statusview event bookingsview book ordersview consultation recordscheck order statusaccess membership informationIf the user is a premium member, the dashboard may also display:next renewal datemembership end date if cancellation is scheduled8. Books and Orders8.1 Browse BooksUsers can browse books through the Resources or Books section.Users can:search by titlefilter by categoryview book priceview member price if applicablesee whether a book is members-only8.2 Add to CartTo add a book to cart:Open the Books page.Select a book.Click Add to Cart.Open the cart icon from the navigation bar.8.3 CheckoutTo complete a purchase:Open the cart.Proceed to checkout.Enter shipping details.Review the order summary.Click the Stripe payment button.Complete payment on the Stripe checkout page.8.4 Pending OrdersIf payment is not completed:the order remains in pending status temporarilythe user may reopen and complete payment while it is still activeif not completed within the allowed time, the system cancels the order automatically8.5 Order TrackingIf tracking is added by admin:users can view the tracking numberusers can open the Australia Post tracking link from the dashboard9. Event Booking9.1 Browse EventsUsers can browse events from the Programs or Events section.Users can:view title, description, date, venue, and pricesee member pricing if applicableidentify members-only events9.2 Book an EventTo book an event:Open the event detail page.Review the event information.Click the booking button.Enter attendee details if required.Complete payment through Stripe.9.3 Event RecordsAfter successful booking:the booking is stored in the systemthe user can view it in the dashboard10. Membership10.1 Membership PlansThe website provides:Free membershipPremium membership10.2 Upgrade to PremiumTo upgrade:Open the Membership page.Review the plan comparison.Click Upgrade to Premium.Complete Stripe payment.After successful payment:the user is upgraded to premiummember pricing and member-only access become available10.3 Manage MembershipPremium users can:open the Stripe customer portalmanage payment detailscancel the subscriptionreview billing settingsIf cancellation is scheduled:premium access remains active until the end of the billing period11. Consultation BookingUsers can book consultations through the Book Consultation page.To use the consultation section:Open the Book Consultation page.Review consultation information.Use the embedded booking calendar or booking link.Select a suitable date and time.Complete the booking process.Users may also submit a consultation request form if available.12. Contact and SupportVisitors and users can use the Contact page to:view the business email addressview phone numberview location detailsview business hourssubmit contact enquiries13. Admin PanelThe admin panel is restricted to admin and owner users only.Admin users can:create, edit, hide, and delete eventscreate, edit, hide, and delete bookscreate, edit, hide, and delete blog postsmanage ordersadd tracking details to ordersmanage users and rolesupdate user membership statusreview contact messages13.1 Admin OrdersIn the admin order section, orders are grouped into:Pending PaymentIn ProgressDelivered / CompletedCancelledAdmins can:view order detailsupdate tracking numberupdate carrier informationmonitor order status more clearly14. TroubleshootingProblem: I cannot log inPossible solutions:check that the email and password are correctreset the password if necessarymake sure the account has already been registeredProblem: My order is still pendingPossible solutions:open the dashboardfind the pending orderclick Complete Payment if availableif too much time has passed, the order may be cancelled automaticallyProblem: I cannot access premium contentPossible solutions:check whether the account is upgraded to premiumrefresh the dashboardconfirm that payment was completed successfullyProblem: I cannot access the admin panelPossible solutions:make sure you are logged in with an admin or owner accountnormal users cannot access admin pagesProblem: My booking or order is not visiblePossible solutions:refresh the dashboardsign out and sign back inconfirm the payment or booking was completed successfully15. Frequently Asked QuestionsQ: Do I need an account to place an order?Yes. Users must sign in before checkout.Q: Can I browse the website without logging in?Yes. Public pages can be viewed without logging in.Q: Can I cancel premium membership?Yes. Premium users can manage subscription settings through Stripe customer portal.Q: What happens if I do not finish payment?The order will remain pending temporarily and can later be cancelled automatically if not completed.Q: Can I track my order online?Yes, if tracking details are added by admin.16.
