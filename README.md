# Mind Architecture Project

## Project Overview

This is a student web development project created for **MIND Architecture**.  
The project focuses on designing and developing a responsive and user-friendly website prototype for the client.

The website is designed to support features such as:
- Event and program display
- User-friendly navigation
- Modern responsive design
- Community and engagement features
- Product and content presentation

## Technologies Used

This project is built using:

- Vite
- TypeScript
- React
- Tailwind CSS
- shadcn-ui

## How to Run the Project

Follow these steps to run the project locally:

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Open the project folder
cd <YOUR_PROJECT_NAME>

# Install dependencies
npm install

# Start the development server
npm run dev
